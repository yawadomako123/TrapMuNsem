# TrapMuNsem

Portfolio site for Big Wilson (Jiggy) — creative director, fashion stylist, and founder of TrapMuNsem.

Built with Vite + React.

## Run locally

```bash
npm install
npm run dev
```

## Edit content

All copy, links, and image choices live in `src/content.js`. Photos are in `public/images/`.

## Build

```bash
npm run build
```

The static site is output to `dist/`.
